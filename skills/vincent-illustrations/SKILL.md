# Vincent 正文配图

把中文内容里的关键判断、流程、状态和隐喻，转成低墨量、近白底、极简线描的 16:9 正文配图。场景保持冷静线条，Vincent 用固定深板岩蓝外套与暖肤色形成稳定 IP 配色，并作为认真工作的 Builder 亲自推动概念成立。

## 先读取

按任务读取，不要一次加载全部参考：

- 始终读取 `references/brand-modes.md` 和 `references/vincent-ip.md`。
- 规划或生成新图时读取 `references/composition-patterns.md`。
- 调用生图工具前读取 `references/prompt-template.md`。
- 生成后读取 `references/qa-checklist.md`。
- 使用 `assets/vincent-avatar.png` 校准身份特征，使用 `assets/vincent-character-sheet.png` 锁定极简线描、全身比例、服装和动作语言。头像不是画风参考。

## 判断入口

- 用户只要求“分析、建议、怎么配图、shot list”时，只输出配图策略，不生图。
- 用户明确要求“生成、直接生成、做图、输出图片”时，内部完成策略后直接逐张生图，不等待确认。
- 用户意图不清时，先输出 shot list。
- 用户要求修改已有图片时，进入编辑流程，不重新设计整张图。

## 选择品牌模式

- 个人博客、作品、社交内容、一人公司叙事、生活化表达：选择**档案态**。
- 教程、方法论、公众号、正式知识内容、产品说明：选择**编辑态**。
- 用户指定模式时服从用户；无法判断时选择**档案态**。

不要双模式混画。档案态最多允许一个编辑态式的克制线框彩蛋；编辑态最多允许一个小型像素签名，占画面不超过 10%。

## 工作流

### 1. 提炼认知锚点

读取用户提供的正文、Markdown、文件、链接、截图或观点。提炼核心判断、认知转折、输入输出、前后差异、断点、角色状态和适合物理化的抽象概念。

不要平均配图。默认规划 4–8 张；短文 1–3 张，长文也不要轻易超过 9 张。

### 2. 形成 shot list

每张写明：

- 放置段落
- 图的主题与一句核心意思
- 品牌模式
- 构图类型
- 物理隐喻
- Vincent 的核心动作
- 主要物件
- 3–5 个建议中文短标注

### 3. 逐张生成

每张只表达一个核心意思，并单独调用一次图片生成工具。

优先使用当前环境原生 `image_gen`。生成前视觉检查头像和角色板，并通过当前工具支持的参考图机制提供两者：头像只负责短发、圆框眼镜、脸型和小胡须，角色板负责最终线描风格、全身比例、服装和动作。明确禁止复制头像的水彩材质，也不要复刻角色板的四人排版。

没有原生工具时，如果已安装 `$codex-imagegen`，读取其说明并用桥接器生成，给每张图同时传入两个身份参考。两者都不可用时，说明缺失的能力并交付完整提示词；不要假装已经生成，也不要静默切换到需要 API Key 的路径。

提示词必须基于 `references/prompt-template.md`，并包含所选品牌模式、身份不变量、构图、准确标注词和避免项。

### 4. 编辑已有图片

把用户提供的图片作为编辑目标。若目标是本地文件，先用 `view_image` 检查，再调用原生编辑流程。将编辑目标放在身份参考之前，并明确：只修改用户指定部分，保持人物身份、姿势、构图、模式、比例和其他文字不变。

默认写入新文件，不覆盖原图。只有用户明确要求替换时才覆盖。

### 5. 检查与迭代

按 `references/qa-checklist.md` 检查生成结果。出现身份漂移、模式混色、人物只是装饰、中文错字、PPT 感、画面过满或比例不对时，只针对一个问题迭代，然后重新检查。

### 6. 保存交付

项目内图片保存到：

```text
assets/<article-slug>-illustrations/
```

按顺序命名：

```text
01-topic-name.png
02-topic-name.png
```

不要覆盖已有资产；使用语义化新文件名或 `-v2`。预览型任务可以只在对话中展示。

交付时简要报告：所选模式、图片数量、每张用途、最终路径、使用的生成方式和最终提示词。指出最稳的必选图与可选图，不长篇解释风格理论。

## 边界

- 3:4 小红书图文卡片或封面：使用 `$rednote-cover-gen`。
- 头像风格转换：使用 `$artifact-template-warm-paper`。
- HTML、Landing、App、公众号 HTML 排版：使用 `$vincent-design-system`。
- 通用图片生成但不要求 Vincent IP：使用通用 Image Gen 能力。
