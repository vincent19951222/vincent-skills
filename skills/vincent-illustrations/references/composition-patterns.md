# 构图与原创隐喻

## 先物理化再画

把每个认知锚点依次转换：

```text
抽象概念 → 一个物理状态或动作 → 一个低科技物件 → Vincent 的关键操作
```

示例：

```text
观点太松散 → 需要压实 → 手摇装订台 → Vincent 调整压力并压出一张可测试卡
```

不要把抽象词直接写进盒子和箭头里。先找一个真实动作：卡住、漏掉、变重、折叠、装订、校准、回流、沉淀、分拣、交付。

## 构图类型

- **概念装置**：一个怪但可信的低科技机器，适合观点、系统或转化过程。
- **前后状态**：同一空间从混乱到有序，Vincent 完成关键转换。
- **断点与修补**：路径中有一个清楚的问题，Vincent 正在接通或加固。
- **工作台剖面**：只展示 3–5 个必要部件，适合流程局部或方法拆解。
- **承重关系**：用架子、桥、夹具、支点表达基础、证据和信任。
- **收集与分流**：用抽屉、文件夹、滑槽、印章或收纳盒表达输入分类。
- **路线与交付**：用纸带、轨道、邮包或门表达从想法到结果。
- **小分镜**：2–4 个连续动作，只有内容确实包含时间变化时使用。

每张只选一种主结构。需要第二层信息时，用一个小纸卡或补充标记，不增加第二套流程。

所有物件都要先做“减线处理”：保留外轮廓、一个功能部件和动作关系即可。抽屉不画木纹，机器不画螺丝，桌子不画透视厚度，地面不画阴影。优先使用平视或近似正投影构图。

## Builder 工作室物件池

优先使用：档案夹、纸带、抽屉、夹具、卷尺、印章、滑轮、旧秤、手摇柄、工作台、梯子、邮包、线轴、闸门、装订器、测试钥匙。

每张选择 1–2 个主要物件。道具总数尽量不超过 5 个，不要把物件池当装饰清单。

## 原创规则

- 从当前文章重新发明隐喻，不复刻 Ian 示例中的小黑、素材鱼、传送带断点、漏斗分流或牵线路径。
- 不把 Vincent 放进已有小黑构图中替换角色。
- 不默认画机器人、芯片、大脑、发光网络、浏览器界面或 Dashboard。
- 同一组图片避免重复主物件和动作；连续两张不要都用箭头流程。
- 怪诞来自“认真执行不寻常但合理的工作”，不是随机堆砌奇怪物体。
