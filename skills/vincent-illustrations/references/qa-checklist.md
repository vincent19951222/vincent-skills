# 极简线描 QA Checklist

## P0：必须通过

- 画面是 16:9 横版正文配图。
- 背景平坦、近白、无纸纹、噪点、暗角和水彩底。
- 墨水覆盖率约不超过 15%–20%，总彩色覆盖率约不超过 10%，视觉空白约 65%–80%。
- 物件只有必要轮廓，没有木纹、螺丝、布料褶皱、排线、投影和材质渲染。
- Vincent 是小型线描操作角色，而不是半写实主视觉人物。
- 短发实心轮廓、圆框眼镜、小胡须线和连帽外套轮廓可辨识。
- Vincent 的脸、耳朵、颈部和手使用同一平坦暖肤色 `#E39A74`，没有明暗和渐变。
- 暖肤色没有出现在衣服、道具、箭头、文字或背景上。
- Vincent 的连帽外套使用同一平坦深板岩蓝 `#2B3B52`，没有渐变、高光和纹理。
- 外套色没有出现在 T 恤、裤子、鞋、道具、箭头、文字或背景上。
- 人物是自然成年人比例，不是 Q 版、吉祥物或照片真人。
- Vincent 承担核心动作；去掉人物后，隐喻不能完整成立。
- 一张图只表达一个核心观点。
- 所选模式正确，颜色只用于点睛，不给人物或物体大面积上色。
- 中文标注只有 3–5 个悬浮手写短词，没有精致铭牌和明显错字。
- 没有类型标题、PPT、课程页、正式流程图、真实 UI 或 AI 刻板符号。
- 构图为当前内容原创，不是 Ian 案例换角色。

## 模式专项

### 档案态

- 钴蓝或森林绿只选择一种功能色。
- 森林绿只有在真实成功状态下才替代钴蓝。
- 没有锈橙和芥末黄。
- 没有大面积品牌色填充。

### 编辑态

- 编辑蓝是唯一功能色，并且只承担一个明确功能；外套色和暖肤色只表示人物。
- 没有浅蓝面板、绿色、橙色、黄色和装饰填色。

## 常见失败与修复

- **像完成插画**：删掉所有填色、纹理、明暗、透视和材质，只保留轮廓。
- **人物太重**：缩小 Vincent，只保留外套与皮肤的固定平涂，确认裤子、鞋和内搭没有填色。
- **人物太冷**：只恢复脸、耳朵、颈部和手的固定暖肤色，不增加服装色或暖色光晕。
- **暖色抢戏**：确认暖色只在皮肤上，删除所有暖色标注、箭头和装饰。
- **外套像完整插画**：删除明暗、褶皱色差、纹理和高光，只留下单一平涂色块与原轮廓线。
- **脸不像**：强化四个身份符号，不增加写实五官和脸部明暗。
- **服装太细**：删褶皱、拉链、鞋带和缝线，只留外套、T 恤、裤子、鞋的轮廓。
- **机器太复杂**：保留一个外框、一个功能部件和 Vincent 的动作，删所有其他零件。
- **太像 PPT**：去掉标题、铭牌、整齐盒子阵列和多余箭头，改成一个平面动作场景。
- **文字出错**：先局部编辑；错得多时减少标注后重生成。
- **颜色太多**：先变成单色线描，再按所选模式只加一处主色。
