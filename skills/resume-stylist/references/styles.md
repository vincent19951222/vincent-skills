## 共用约束

- 语义化 class 契约见 `references/skeleton.md`，皮肤只通过 CSS 选择器生效
- bullet 关键数字 `<strong>` 包裹，皮肤可对 `strong` 做高亮（下划、色块、品牌色）
- 06/07 面向国内 HR 筛选场景：强调色克制使用，装饰元素不过度，屏幕与打印效果一致
- 像素字体（FusionPixel）base64 已内嵌在 04/05 中，新皮肤需要时原样复制，只用于标题层
