# 简历交付规范

> 默认交付一对同源文件：可继续编辑的 HTML，以及由该 HTML 生成并验证过的 PDF。

## 输出目录

1. 用户指定目录时使用该目录。
2. 用户未指定时，在当前工作区使用 `output/resume/`。
3. 不把临时浏览器数据、验证日志或预览图混入交付目录。

## 文件命名

共同基名：

```text
姓名-意向岗位-简历-风格名
```

默认产物：

```text
姓名-意向岗位-简历-风格名.html
姓名-意向岗位-简历-风格名.pdf
```

- 去除文件名中的 `/ \\ : * ? " < > |`，连续空白改为单个连字符。
- HTML 与 PDF 必须在同一目录并使用相同基名。
- 已存在同名文件时不要静默覆盖。默认追加 `-v2`、`-v3`；用户明确授权后才覆盖。
- 验证产生的 PDF 通过全部检查后直接作为最终 PDF，不再手动另存一份来源不明的 PDF。

## 格式选择

- 用户未指定：交付 HTML + PDF。
- 用户明确只要 HTML：仅交付 HTML，但仍可生成临时 PDF 做布局验证；验证后删除临时 PDF。
- 用户明确只要 PDF：交付 PDF；保留同源 HTML 直到任务完成，以便修订，但不必展示给用户。
- 用户要求其他格式时单独处理，不把 DOCX、图片或 Markdown 当作默认产物。

## 验证与交付

交付前依次确认：

1. `scripts/check-output.mjs` 通过。
2. `scripts/validate-layout.mjs` 通过，最终 PDF 为 1 页 A4。
3. 最新 PDF 已渲染为 PNG 并完成视觉检查，没有裁切、重叠、黑块或缺字。
4. 内容填充达到页面高度的 85–95%；资料较少时通过字号、行距和区块留白调整，不编造内容填空。
5. HTML 与 PDF 基名一致，且确实来自同一版本内容。
6. 临时 PDF、PNG、浏览器 profile 和日志已清理；用户要求预览图时除外。

自动 PDF 依赖不可用时，不要静默降级：说明缺少的命令和安装方式。只有用户明确接受后，才能仅交付 HTML 或标记为“PDF 未自动验证”。

## 用户自行打印设置

用户需要从 HTML 重新打印时，给出以下设置：

- 浏览器：Chrome / Chromium
- 纸张：A4，纵向
- 缩放：100%，不要“适合页面”
- 边距：使用模板的 CSS `@page`，不要增加自定义边距
- 页眉和页脚：关闭
- 背景图形：开启

## 最终回复模板

```markdown
已完成并验证：

- [HTML 源文件](/absolute/path/姓名-意向岗位-简历-风格名.html)
- [PDF 投递版](/absolute/path/姓名-意向岗位-简历-风格名.pdf)

验证：成品内容检查通过；PDF 为 1 页 A4；字体、溢出和可提取文本检查通过；PNG 视觉复核无异常。
```

回复只保留用户需要知道的结果和验证状态，不暴露临时目录、浏览器 profile 或内部命令输出。
