# 统一小红书主角封面模板

本文件只用于组装最终 ImageGen 提示词。默认先完成交互草案，用户确认后才调用生图工具。

## 输入变量

- `{{标题原文}}`：用户提供的标题，不改写
- `{{标题排版}}`：只通过换行和大小层级组织标题
- `{{大概内容}}`：用户提供的内容、观点或经历
- `{{用户约束}}`：用户希望出现或避免的元素；没有则写“无”
- `{{主角来源}}`：参考图、用户文字描述或自动设计
- `{{主角设定}}`：确认后的身份、外观、服装或配饰、拟人程度与画风
- `{{身份约束}}`：按人类、动物或虚构角色生成的一致性约束
- `{{主角状态}}`：确认后的动作和表情
- `{{画面内容}}`：确认后的场景和道具
- `{{整体情绪}}`：确认后的表达语气
- `{{配色}}`：确认后的两个主色和一个强调色

## 统一生图提示词

```text
Use case: ads-marketing
Asset type: 小红书竖版 IP 内容封面，3:4

Primary request: 根据用户提供的标题和内容生成一张有明确个人表达、适合手机端阅读的小红书封面。内容可以是吐槽、教学、情感、观点、个人经历或日常分享，不要强行改造成教程、测评或知识付费广告。

User content: {{大概内容}}
User constraints: {{用户约束}}

Subject source: {{主角来源}}。

Subject: {{主角设定}}。当前状态：{{主角状态}}。主角要有真实表达感，动作和表情必须自然并服务于内容。人类、动物和虚构角色都可以；不要强制把动物变成人类身体。不要使用夸张营销动作、导师式指点或过度震惊表情。

Scene/backdrop: {{画面内容}}。只保留一个容易理解的主场景和少量必要道具。场景要提供内容线索，而不是堆放装饰。复杂界面只做抽象轮廓，不复制真实软件 UI，不显示无关品牌 logo。

Style/medium: 有参考图时，严格延续参考图的角色比例、线条、上色和插画质感；没有参考图时，严格执行已确认的主角设定，默认采用明亮、细腻的半写实轻漫画插画。整体自然、有个人气质，兼具生活感和轻微编辑海报感；不幼稚、不油腻、不像商业培训广告。

Composition/framing: 竖版 3:4，采用统一组合结构：标题位于画面上半部或左上视觉区，主角位于中下部或右侧，关键场景道具与主角产生明确互动。主角占约 42%-55%，标题占约 25%-35%。标题、头部和四肢完整，手机缩略图下仍然清楚。画面饱满但保留呼吸空间。

Text (verbatim): 画面只允许出现用户标题：“{{标题原文}}”。按照以下层级排版，但不得改变、增删或重复任何字词：“{{标题排版}}”。除非用户约束中明确提供了其他文案，否则不要出现副标题、标签、按钮文字或背景小字。

Typography: 使用清晰、有编辑感的中文粗黑体或手写粗体。通过字号、换行和一个重点色建立层级，可使用适量描边或投影保证可读性。不要堆叠多种字体和贴纸特效，不要把每个字做成独立气泡。

Color palette: {{配色}}。只使用两个主色和一个强调色。强调色只用于标题关键词、关键道具或一个视觉焦点，避免单一颜色铺满画面。

Decoration: 最多使用两类非文字辅助元素，例如一条箭头、一个圈选、少量星点、波形或简单线条。装饰只负责引导视线，不填满所有空隙。

Lighting/mood: {{整体情绪}}。使用明亮自然光或柔和室内光，主角面部或主要表情区域清晰，轻微轮廓光，整体像主角正在表达这件事，而不是在销售课程。

Identity constraints: {{身份约束}}。

Constraints: 主角身份和画风一致；肢体或动物四肢自然；标题逐字准确且只出现一次；生成一张完整封面；无水印、二维码和无关 logo。

Avoid: 假中文、乱码、标题改写、缺字、多字、重复文字、多余英文、裁切主角头部、裁标题、角色身份漂移、脸部或动物面部崩坏、肢体崩坏、擅自改变动物物种或拟人程度、导师感、销售感、知识付费海报感、复杂界面、装饰堆砌、纯色空背景、画面过空或过乱。
```

## 草案判断原则

- 先理解内容想让读者感受到什么，再选择表情和道具。
- 教学内容突出“正在演示”，不自动添加“新手必看”等营销文案。
- 吐槽内容使用反差、无奈或轻微夸张，不把人物做成愤怒表情包。
- 情感内容允许安静、克制和留白，不强行增加点击率贴纸。
- 日常内容保留具体生活环境，不包装成教程。
- 道具最多保留一个主道具和一个辅助线索。

## 主角来源写法

### 有参考图

```text
Image 1 是主角身份与插画风格参考图。严格保持同一角色和同一绘画媒介。
```

### 文字描述或自动设计

```text
没有参考图。根据已确认的主角设定生成一个明确、可重复识别的角色，不添加未确认的显著特征。
```

## 身份约束写法

- 人类：锁定脸型、五官比例、发型、年龄、肤色、眼镜、服装和绘画媒介。
- 动物：锁定物种或品种、身体比例、毛色、花纹、眼睛、耳朵、尾巴、配饰和拟人程度。
- 虚构角色：锁定外轮廓、身体比例、材质、主色、标志性特征、配饰和绘画媒介。
