# Vincent 像素人物 IP

## 参考图职责

- `../assets/vincent-avatar.png` 是唯一人物身份参考。主动匹配可辨识的脸型、眉眼比例、眼镜位置、发际线、短发轮廓、鼻口关系和稀疏胡须，而不是只生成一个泛化的“戴圆眼镜亚洲男性”。
- 忽略头像的水彩笔触、柔和光影、肤色纹理和胸像构图；只把人物身份转换为等距 16-bit 像素画。
- 不读取或传入相邻 Skill 的角色板。成人比例、服装和 Builder 动作只使用本文件的文字规则。

不要只靠文字重建人物。生成一组图片时，每张都继续使用同一张头像，并把面部相似度放在姿势细节和场景装饰之前。

## 固定像素特征

- 成年东亚男性，自然偏瘦，约 5.5–6 头身；不是儿童、Q 版或大头吉祥物。
- 脸型偏修长的柔和椭圆形，下颌收窄但不尖；耳朵自然可见。
- 眉毛较直、清楚，眼睛位于圆框中央；不要画成夸张动漫大眼。
- 使用细黑色正圆镜框，两个圆框大小和高度稳定，鼻梁连接短而清楚。
- 短而略蓬松的黑发，顶部有不规则尖束，额前碎发自然下落；不要改成整齐锅盖头或高耸刺猬头。
- 用极少深色像素表示稀疏上唇胡须、下唇下方短胡须和小山羊胡；不要画成浓密络腮胡或粗黑八字胡。
- 敞开的连帽外套使用深板岩蓝 `#2B3B52` 附近色，内搭为浅色无图案 T 恤。
- 裸露皮肤使用暖桃色 `#E39A74` 附近色；长裤和低帮鞋保持低调深浅中性色。
- 表情冷静、友好、专注，带一点认真做怪事的幽默。

## 角色职责

让 Vincent 承担核心动作：搬运、拼装、校准、接线、搭桥、修补、分类、测量、种植、测试、装箱或交付。

动作必须解释内容。如果移除 Vincent 后隐喻仍然完整，重写构图。优先使用正面或三分之四侧面，让头像锚点可被识别；避免背面和极端侧脸。人物过小时先放大 Vincent，再删场景装饰。发型、圆眼镜、眉眼比例、胡须提示和蓝色开襟外套不能同时丢失。

## 允许变化

- 根据动作改变姿势、视角和表情强度。
- 可蹲下、攀爬、推拉、弯腰、卷袖或被装置轻微卡住。
- 可拿一个与主题直接相关的主要工具。
- 时间序列分镜可出现多个 Vincent，但必须明确是同一人的连续动作。

## 禁止漂移

- 不改变年龄、族裔、脸型、眉眼比例、发型、圆框眼镜或胡须类型。
- 不换成西装、制服、主题 cosplay、盔甲、帽子或套头帽衫。
- 不画成 3 头身、可爱吉祥物、肌肉英雄、商业 3D 人偶或照片真人。
- 不用高分辨率五官、写实手指、柔和皮肤明暗或布料纹理破坏 sprite 一致性。
- 不把脸重新设计成泛化动漫男孩、圆脸像素 NPC 或只靠眼镜识别的陌生角色。
- 不让 Vincent 只举标题牌、站在角落或面对与主题无关的电脑屏幕。
