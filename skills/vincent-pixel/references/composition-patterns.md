# 等距像素构图与原创隐喻

## 先物理化再像素化

依次转换：

```text
抽象概念 → 一个可观察的物理状态 → 一个微缩工作场景 → Vincent 的关键操作
```

示例：

```text
信息没有形成闭环 → 回路断开 → 两个平台之间缺一段轨道 → Vincent 正在安装最后一节桥轨
```

不要把抽象词直接塞进面板和箭头。先找动作：搬运、拼接、校准、种植、修补、装箱、点亮、分流、回收、交付。

## 构图类型

- **单体微缩工坊**：一个开放式工作台或房间切片，适合方法、系统和生产过程。
- **平台与桥接**：两个高低平台通过桥、轨道或线缆连接，适合迁移、协作和断点。
- **路径与关卡**：一条清楚的折线路径穿过 2–4 个节点，适合阶段、选择和交付。
- **装置与转化**：输入物进入一台结构清楚的低科技机器，输出可见结果。
- **收集与分流**：用箱子、滑槽、抽屉、温室格或货架表达分类和积累。
- **承重与维护**：用支柱、脚手架、齿轮、阀门或补丁表达基础、稳定和修复。
- **前后双区**：同一等距网格划分为前后两个状态；只在内容确实依赖对比时使用。

每张只选一种主结构。封面优先单体微缩工坊、平台桥接或装置转化；正文配图可使用更轻的路径和局部装置。

## Builder 物件池

优先使用：工作台、档案箱、轨道、桥板、滑轮、手摇柄、齿轮、温室格、邮包、灯塔、闸门、梯子、线轴、测量尺、测试终端、工具柜。

每张选择 1–3 个主要物件。终端只能作为场景道具，不要把整张图变成 UI 截图。

## 原创规则

- 从当前文章重新发明隐喻，不把现成的像素房间、游戏关卡或他人构图换成 Vincent。
- Vincent 必须改变场景状态；不能只站在角落、指向装置或充当头像贴纸。
- 同一组图片避免重复主物件、动作和平台轮廓；连续两张不要都使用传送带或桥。
- 欢快和温暖来自色彩、认真劳动和微小生活细节，不来自塞满盆栽、咖啡杯和装饰灯。
- 不默认使用机器人、大脑、芯片、霓虹网络、数据宇宙等 AI 刻板符号。
