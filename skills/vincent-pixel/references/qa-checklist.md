# Vincent Pixel QA Checklist

## P0：必须通过

- 比例与发布位置一致：公众号头条封面是 2.35:1（参考 900×383），通用封面、正文配图和小红书 HTML 卡片内嵌主视觉是 16:9。
- 公众号头图的 Vincent、核心物件和不可裁切信息位于中央偏上安全区；左右边缘和底部只有可损失内容，能承受方形分享裁切与平台标题遮挡。
- 第一眼是真正的等距 16-bit 像素场景，不是模糊插画、3D 渲染或后期马赛克滤镜。
- 像素块清楚、边缘坚硬，没有抗锯齿、渐变、景深、辉光和柔边阴影。
- 全图使用同一套约 `±26.565°` 等距轴线，竖线垂直，物体尺度一致。
- 调色板鲜明但受控；材质使用有限硬色阶和克制 dithering。
- 缩略图状态下主场景、Vincent 的动作和核心关系仍清楚。
- Vincent 是自然成年人比例，不是 Q 版、儿童或吉祥物。
- 对照头像，修长柔和的椭圆脸、收窄下颌、直眉、眼睛与细圆框的位置关系、短碎黑发、稀疏上唇胡须和小山羊胡可辨识；不能只是泛化的眼镜男角色。
- 人物优先使用正面或三分之四侧面；面部像素不足时应放大人物并删减道具。
- Vincent 承担核心动作；去掉人物后，隐喻不能完整成立。
- 一张图只表达一个核心观点，主要物件 1–3 个，道具不过量。
- 欢快、温暖，但没有被盆栽、灯串、杯子等“cozy 装饰”淹没。
- 没有 HUD、血条、游戏菜单、对话框、Logo、水印或无关标题。
- 图内文字严格等于 shot list 白名单；没有顶部状态栏、Emoji、心情、编码状态、AI 百分比、电量、电源、信号或其他与文章无关的装饰信息。
- 通用封面需要排字时有真实可用的标题安全区；公众号头图底部干净，不依赖图内文章标题；正文图不会重复大标题。
- 小红书 HTML 卡片内嵌主视觉没有任何图内文字、页码、徽章、品牌边框或卡片 UI；这些由 HTML 模板负责。
- 正文配图默认包含 2–5 个与物件或关系自然结合的简短中文像素批注；只有用户明确要求纯图片时才能无字。
- 需要中文批注的正文图由图片生成模型直接生成，逐字正确、清晰可读，没有额外幻觉文字；卡片内嵌主视觉的文字白名单为空。
- 构图为当前内容原创，不是现成像素游戏场景换角色。

## 常见失败与修复

- **像 3D 渲染**：删除材质高光、环境遮蔽和柔光，改成有限色阶、硬边与逐格像素轮廓。
- **像素只是滤镜**：重建规则网格、sprite 尺度和逐格轮廓，不保留原来的平滑曲线。
- **边缘发糊**：明确 no anti-aliasing、no blur、nearest-neighbor-like crisp pixels，并减少微小细节。
- **等距角度乱**：统一左右轴、垂直线和物体厚度，删除不服从网格的道具。
- **人物太 Q**：缩小头部、拉长四肢与躯干，恢复 5.5–6 头身成人比例。
- **人物不像**：只对照头像，先放大 Vincent 15%–25%，使用正面或三分之四侧面，再校准椭圆脸、下颌、直眉、眼睛与圆框位置、短碎发和稀疏胡须；不要引用角色板，也不要增加写实五官。
- **场景太满**：删到 1–3 个主物件和一个动作，恢复标题安全区或背景空区。
- **公众号封面比例或裁切错误**：重生成 2.35:1 画布，把主体移回中央偏上安全区，删除底部及两侧的关键文字和不可替代物件；不要用 16:9 成图硬裁冒充。
- **颜色脏**：减少相近色和无意义 dithering，让每个材质只保留 2–4 个明暗阶。
- **像游戏截图**：删除 HUD、边框、菜单和对话框，只保留独立场景资产。
- **出现通用顶部信息条**：删除“心情、编码中、AI 百分比、电源、信号”等白名单外内容；顶部只有在文章主题和 shot list 明确需要时才能保留主题批注。
- **出现白名单外文字**：优先局部编辑删除所有额外字符；若无法完整清除则用同一白名单重生成，不接受“意思差不多”的替换词。
- **文字出错**：优先局部编辑；仍不稳定时减少批注数量并重生成。不得静默删除全部文字或用后期脚本叠字；只有用户明确接受无字版本时才能降级。
- **卡片内嵌主视觉出现文字或 UI**：局部删除所有字符、页码、徽章、边框和面板；无法完整清除时以空文字白名单重生成，不把错误内容带进 HTML。

## 交付判断

缩略图状态下应先看到一个精确、欢快、干净的微缩等距场景，以及正在认真工作的 Vincent。公众号头图在 2.35:1 列表展示和中心方形裁切下都不丢失核心主体；正文图的短中文批注能进一步解释关键关系。放大后每个像素边缘和中文字形仍清楚，细节丰富但不拥挤。
