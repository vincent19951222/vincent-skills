# Vincent Pixel 视觉系统

## 核心视觉合同

- 画布：微信公众号头条封面使用 `2.35:1`，以 `900×383` 为参考尺寸；通用博客封面、正文配图和小红书 HTML 卡片内嵌主视觉使用 16:9。所有类型都只使用一个单一等距场景。
- 风格：isometric pixel art、16-bit game asset style、crisp and sharp distinct pixels、hard edges、vibrant distinct color palette、clean dithering、precise geometry、cheerful and cozy atmosphere、professional sprite work、detailed but uncluttered。
- 投影：使用稳定的等距或 2:1 pixel isometric 网格，左右轴约为 `±26.565°`，竖线保持垂直；全图只使用一套轴线。
- 像素：像素块必须肉眼可辨，边缘逐格清楚，不抗锯齿、不模糊、不使用矢量平滑曲线。
- 几何：物体落在同一网格与尺度体系中；台阶、地砖、柜体和机器的厚度保持一致。
- 完成度：像专业游戏场景资产，不像给插画套了一层马赛克滤镜。

## 色彩与光影

- 总调色板控制在约 18–32 个清晰颜色；单个材质通常只用 2–4 个明暗阶。
- 基础深色使用墨蓝 `#172033` 附近色，避免纯黑吞掉细节。
- Vincent 的连帽外套保持深板岩蓝 `#2B3B52` 附近色，裸露皮肤保持暖桃色 `#E39A74` 附近色。
- 背景和空区可使用暖奶油色 `#FAF7EF` 附近色；场景允许加入清晰的蓝、绿、橙、黄，但不要把所有颜色都平均铺开。
- 用硬边、有限色阶表达光照；允许克制的棋盘或条带 dithering，不使用渐变、柔光、辉光或空气透视。
- 阴影必须是像素化硬阴影，并服从同一光源；不要使用柔边环境遮蔽。

## 密度与构图

- 通用 16:9 封面主体约占画面 55%–70%，正文配图约占 35%–60%。
- 小红书 HTML 卡片内嵌主视觉主体约占画面 45%–70%，保持轮廓清楚，并允许 HTML 在图片外部承担标题、正文和页码。
- 公众号 2.35:1 头图把 Vincent、核心物件和不可裁切信息集中在中央约 43% 宽度的方形安全区及其上半部；左右两侧用于可裁切的环境延伸，底部避免关键人物、文字和结果信息。
- 主要物件控制在 1–3 个，道具总数尽量不超过 7 个。
- 细节用于解释功能，不用于铺满表面。缩略图状态下仍应先看到主场景、Vincent 的动作和一条清楚的信息关系。
- 通用封面需要后期标题时，保留一块轮廓简单、对比稳定、无遮挡的安全区；不要用随机小物填满它。公众号头图默认依赖平台标题，不在底部安排后期标题区。

## 文字规则

- 封面默认不烘焙文章标题。通用封面保留后期标题安全区；公众号头图把主体放在中央偏上，并为平台标题遮挡保留干净底部。
- 正文配图默认直接生成 2–5 个简短中文像素批注，每处尽量 2–8 个字，用于说明输入、输出、状态、转折或结果；不要重复文章标题。
- 小红书 HTML 卡片内嵌主视觉固定无字；卡片标题、正文、页码、徽章和签名全部由 `$vincent-design-system` 的 HTML 模板负责。
- 批注必须由图片生成模型在生成场景时直接完成，并与物件、箭头或空间关系自然结合；不要通过脚本、Canvas、SVG 或后期排字叠加。
- 每张图先建立严格文字白名单。图内只能出现白名单中的精确字符，不得添加任何为了营造游戏感或科技感而虚构的状态文字。封面默认文字白名单为空。
- 顶部和角落不默认放信息条。只有当文章主题确实需要且 shot list 明确指定时，才能在这些位置放与主题直接相关的白名单批注。
- 只有用户明确要求“纯图片、无字底图”时，正文配图才不生成文字；小红书 HTML 卡片内嵌主视觉是固定例外，默认无字。
- 中文字形必须清晰、逐字正确并落在同一像素网格上；不得擅自发明额外文字。
- 不生成 HUD、状态栏、血条、菜单、对话框、按钮或游戏截图边框，除非内容本身明确讨论这些元素。
- 禁止无关 Emoji、心情、编码状态、AI 百分比、电量、电源、信号、等级、日期、时间或设备标签，例如“👾 心情：编码中”“📡 AI：99%”“电源”。

## 绝对禁止

- 抗锯齿、模糊、景深、运动模糊、柔边阴影、渐变、体积光和电影噪点。
- 矢量插画、低多边形、voxel、黏土 3D、等距 3D 渲染、预渲染手游场景。
- 在普通插画或照片上叠加像素化滤镜。
- 混用不同像素尺寸、不同等距角度或相互冲突的透视。
- 过度微缩、密集城市、满屏小物、复杂机械内部和无法辨认的装饰纹理。
- 默认添加游戏 UI、品牌 Logo、水印或无关标题。
