# Scene 交互与导航

默认显示 L0 观点 + L1 结构。选择进入 L2 解释，只有确有内容时进入 L3 证据/模拟。

- Hover 表示可操作，Click 进入信息；不能靠 hover 才能读到核心解释。
- 节点选中同步突出相关边，文字说明也必须指出关系。
- Drawer 打开时背景轻 Dim，退出回到选中对象。关闭、Escape、触控、键盘入口均可用。
- Focus / Zoom 放大实际对象，保留“返回概览”；不让用户迷失于拖拽画布。
- Scene 上一页、下一页、章节入口保持明确。面板开启和输入控件聚焦时不捕获全局翻页键。
- 演讲模式、全文阅读、播放等能力按使用情境选取，不以同一套全局功能强加到每个项目。

无需强制三屏开场。选最能验证内容关系和信息深度的样板，随后按授权完成所需内容。
