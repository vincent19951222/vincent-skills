# 交付验收

## 内容与叙事

- [ ] 每屏一个核心问题、一个视觉主角、最多三个主要信息组。
- [ ] L0/L1 默认可读，L2/L3 增加解释与证据，而非重复。
- [ ] 来源、版本、单位、模拟数据清楚，不把模板示例当产品事实。

## 视觉

- [ ] 暂停动画仍然成立；标题、主图和关系的主次明确。
- [ ] 原 Logo 完整，UI 红与状态色职责不同。
- [ ] Base / Dot Grid 按内容选择；4/6/8px 圆角、hairline、阴影遵循统一规则。
- [ ] 字号和留白随容器适配，关键数字/参数使用 Mono。

## 交互

- [ ] 选中节点与相关路径联动，Drawer 提供关闭与焦点返回。
- [ ] 键盘和触控可用，隐藏内容不留在 Tab 顺序中。
- [ ] 打开 Drawer 不意外翻页；窄屏有可见 Scene 导航。
- [ ] 关闭、Escape、重复打开均无状态残留。

## Motion 与技术

- [ ] 每个动效有语义，同时最多一个主效果；减少动效后内容不丢失。
- [ ] 模板从 file URL 打开，Logo 加载；1440/768/390/320px 无页面横溢出。
- [ ] 不因风格默认引入 GSAP/Three.js。没实现的能力不标已完成。
