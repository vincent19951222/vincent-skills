# Validation workflow

1. Open the HTML directly and through a local server.
2. Check 1440×810, 768×900, 390×844, and 320px widths.
3. Use keyboard only: Tab to controls, Enter/Space to activate, Arrow keys to change slides, Escape to leave fullscreen.
4. Test a long Chinese title, a missing image, a selected flow node, and `prefers-reduced-motion`.
5. Check the logo's transparent padding and its visible size at desktop and mobile.
6. Confirm no horizontal overflow and no console errors.
7. Before delivery, run the skill validator and inspect the final asset paths.
